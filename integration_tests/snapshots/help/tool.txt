tool

  Snapshot tool

USAGE:
  tool [flags] <command>

COMMANDS:
  run, r          Run target

FLAGS:
  --verbose, -v         (bool) default=false — Verbose output
  --debug, -d           (count) (repeatable) — Increase debug verbosity (repeatable)
  --color               (auto|always|never) default="auto" — When to colorize output

FLAG GROUPS:
  display             at least one required: --verbose, --color — Choose at least one display control.
